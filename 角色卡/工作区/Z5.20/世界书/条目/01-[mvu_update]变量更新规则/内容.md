---
变量更新规则:
  世界:
    时间:
      format: HH:MM
      check:
        - 每次事件推进后更新时间
        - 保持时间流逝合理
    日期:
      format: M月D日
      check:
        - 跨天时更新日期
        - 同时更新星期

  公寓:
    房间列表.${房间名}:
      type: |-
        {
          类型: string;
          名称: string;
          楼层: string;
          位置: string;
          住户: string;
          描述: string;
        }
      check:
        - 新建、改造、拆除房间时更新
        - 楼层值必须是楼层列表中的有效值
        - 位置格式为 "起始-结束"(如"1-3") 或 "outdoor-left"/"outdoor-right"
      住户字段铁则:
        - 住户字段代表【永久居住分配】，不是租客当前位置
        - 【只有】新租客入住 或 租客退租 时才能修改住户字段
        - 租客临时使用其他房间（做饭、看电视、散步等）绝不修改住户字段
        - 合租时用顿号分隔多个姓名，如 "张小雪、林诗涵"
        - 退租时从住户字段中移除该租客姓名（若只剩一人则改为"无"）

  租客列表:
    type: |-
      {
        [租客姓名: string]: {
          年龄: number;
          外貌: string;
          职业: string;
          性格: string;
          状态: string;
          内心: string;
          关系: { [对象名: string]: string };
        }
      }
    check:
      - 新租客入住时添加条目（包含所有必要字段）
      - 租客退租时移除条目
      - 状态和内心随剧情实时更新
      - 关系变化时更新关系字段

  分基地:
    type: |-
      {
        [基地名: string]: {
          描述: string;
          住户: string[];
        }
      }
    check:
      - 分基地的创建和删除由脚本管理，AI不应自行添加或删除基地
      - AI可以更新分基地内租客的住户列表（如租客搬入搬出）
      - 分基地住户必须同时存在于租客列表中
