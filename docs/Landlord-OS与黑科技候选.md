# Landlord OS 与黑科技功能候选

> 状态：设计储备，尚未进入实现阶段。
>
> 目标：不改变“装修与招募”的主线玩法，通过真实的系统能力、可视化和工程架构，让角色卡呈现出接近独立软件的技术质感。

## 已保留方案：Landlord OS｜房东操作系统

Landlord OS 是统一承载掌上公寓、手机、创意工坊、MVU、AI 任务和模块管理的系统中枢，而不是单纯的新皮肤。

核心组成：

- 多窗口桌面：窗口拖动、缩放、吸附、最小化、并排和位置记忆。
- 全局命令面板：通过 `Ctrl/Cmd + K` 搜索并执行系统命令。
- 模块全息图：显示模块依赖、启动状态、加载耗时、能力和错误。
- MVU 观测站：浏览变量、Patch 差异、Zod 验证结果、历史快照和回滚。
- AI 任务中枢：展示“提示词 → 请求 → 解析 → 校验 → 写入 MVU”的真实流水线。
- 更新中心：显示版本、CDN 状态、文件哈希、本地缓存与回滚入口。

建议分期：

1. 桌面外壳、窗口管理器、命令面板。
2. 模块图与真实运行状态。
3. MVU 观测站和时间线。
4. AI 任务中枢与更新中心。

## 其他黑科技候选

### 1. World Blueprint｜世界逻辑蓝图

制作类似 Unreal Blueprint、Node-RED 的可视化节点编辑器。创作者可以把“事件、条件、AI 生成、变量更新、界面通知”连接成一张真正可执行的图。

示例：

```text
收到 AI 回复
  → 检测是否出现新租客
  → 调用额外模型整理档案
  → Zod 校验
  → 写入 MVU
  → 刷新公寓和手机
```

蓝图保存为 JSON，由编译器生成标准事件处理流程。它不是图片展示，而是可以运行、暂停、单步调试和查看每个节点输入输出的程序。

评价：视觉冲击最强，代码含金量高，也能降低以后增加模块的维护成本。

### 2. Prompt X-Ray｜提示词透视仪

捕获真正发送给 AI 的最终提示词，并展示每一段内容来自哪里：角色定义、世界书、聊天记录、EJS 模板、MVU 状态或临时任务。

可提供：

- 世界书触发记录与触发原因。
- 每个来源占用的 Token 数。
- 模板渲染前后对比。
- 本次与上次请求的差异。
- 点击任意段落定位原始来源。
- 提示词过长、重复或互相冲突的诊断。

评价：比假终端更有技术感，能真正回答“AI 为什么会这样回复”。

### 3. MVU Self-Healing｜变量自愈协议

在 JSON Patch 正式执行前先放入影子状态中试运行，通过 Zod 和路径规则检查结果，再决定提交、修复或拒绝。

能力包括：

- 自动创建缺失的父对象。
- 检测对象、数组和原始值之间的类型冲突。
- 把旧版本变量迁移到新 Schema。
- 预览一次 Patch 将修改什么。
- 对危险更新生成修复建议。
- 失败时保留原状态并允许一键重试。

评价：实用性最高，可以直接处理类似 `用户.物品栏` 不存在的问题。

### 4. Memory Neural Graph｜记忆神经图谱

把人物、房间、事件、关系和物品整理成可检索的知识图谱，并在界面中显示为可缩放的动态网络。

底层可以使用 IndexedDB 保存数据，通过向量检索或关键词检索，只把当前剧情最相关的记忆注入提示词。

评价：看起来很炫，也能改善长对话遗忘；但需要处理向量模型、额外 API 消耗和存储升级。

### 5. Parallel Timeline Lab｜平行时间线实验室

在不破坏当前存档的情况下复制完整 MVU 状态，建立多个剧情分支，并比较两个分支的变量和角色变化。

能力包括：

- 从任意快照创建分支。
- 为不同分支设置不同世界观或建筑状态。
- 对比两条时间线的变量差异。
- 选择性合并人物、房间或物品。
- 随时返回主时间线。

评价：技术上非常亮眼，但需要谨慎处理 SillyTavern 聊天文件与 MVU 状态的对应关系。

### 6. Mod Capability Sandbox｜模组能力沙箱

让创意工坊下载的扩展包不能随意访问全部页面，而是必须声明权限：

```text
mvu.read
mvu.write
ai.generate
ui.window
worldbook.install
storage.local
```

系统根据 manifest 提供有限能力，并支持依赖解析、哈希校验、热启停、版本锁定和故障回滚。

评价：工程含金量最高，能把创意工坊从素材库升级为真正的 MOD 平台。

### 7. Multi-Agent Forge｜多智能体锻造台

一次内容生成由多个可替换阶段共同完成，例如：生成者、设定校验者、MVU 结构化处理器和质量评审者。界面显示每个阶段的输入、输出、耗时和结论。

评价：展示效果很强，但会增加副 API 调用次数，应当作为可选高级模式。

### 8. Adaptive Visual Engine｜自适应视觉引擎

从角色头像、壁纸或世界观封面提取主色、明暗和对比度，实时编译 CSS 变量、渐变、辉光、图标配色与窗口主题。

评价：实现周期较短、视觉反馈明显，但技术深度低于蓝图、提示词透视和能力沙箱。

## 初步优先级

如果目标是“第一次打开就觉得很牛”，优先考虑：

1. World Blueprint｜世界逻辑蓝图。
2. Landlord OS｜房东操作系统。
3. Memory Neural Graph｜记忆神经图谱。

如果目标是“真正提升稳定性和维护能力”，优先考虑：

1. MVU Self-Healing｜变量自愈协议。
2. Prompt X-Ray｜提示词透视仪。
3. Mod Capability Sandbox｜模组能力沙箱。
