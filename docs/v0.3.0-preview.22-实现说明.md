# v0.3.0-preview.22 实现说明

这一版把 24H 生活流线从“可视化预演”升级成了可玩事件。跨世界生活交汇预言机会找出不同人物在同一时段的空间交汇，玩家可以从候选中锁定一次，让预演变成真正的双人生活场景。

## 交汇检测

- `同屋相遇`：两条流线在同一时段落到同一个空间。
- `相邻擦肩`：人物落在同一建筑的两个相邻空间，建筑模型中存在已知通路。
- `同栋共振`：人物在同一时段使用同一栋建筑的不同区域，仍有成为共同事件的机会。
- 只检查白日主场与晚间碰撞，不把起床和回住处自动判定为社交事件。

## 交汇强度与可解释原因

- 关系引擎新增可复用的人物组合评估接口，预言机不再重写职业、世界来源和性格规则。
- 分数同时受空间活力、舒适、同屋/相邻/同栋距离、晚间时段与现有关系影响。
- 每张候选卡显示时间、人物、来源世界、目标空间、两人路线类型与最多三条可解释原因。
- 两人从当前位置到目标空间的路线必须都通过校验，任何一方不可达时都不显示候选。

## 锁定后才真正发生

- 点选候选卡只更改界面中的当前选择，不修改人物、建筑或事件。
- 点击“锁定交汇”后，两人才会同步前往目标空间并更新当前状态。
- 写入复用原有双人生活场景事务：两人位置要么一起成功，要么全部不生效。
- 锁定前任意人物已移动时，旧候选会拒绝覆盖新位置。
- 锁定创建建筑事件、正文/微信/建筑三频道草稿，并自动进入经营回溯。

## 工程与本地验收

- 自动化回归测试：100/100 通过。
- 新增三项测试，覆盖可达跨世界交汇检测与无副作用、双人原子写入与三频道联动、“选中不写入/确认才生效”交互边界。
- 最终 bundle 功能合同覆盖预言机、候选类型和两个锁定动作。
- 浏览器验收覆盖 1440px 桌面和 500px 手机布局，选中状态与锁定确认条可见，无页面溢出、无 `undefined`、无控制台警告或错误。
- 测试和视觉验收全程未调用真实 AI，未发送 SillyTavern 对话。
- 在线版和离线版仍各自只有一条酒馆助手脚本；角色卡和世界书使用独立 `0.3.0-22` 名称。
