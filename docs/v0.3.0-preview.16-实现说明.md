# v0.3.0-preview.16 实现说明

这一版让装修从“看三张方案卡”变成真正的空间预演。玩家选中方案后，系统会把它无副作用地投射进目标房间所在的数字孪生楼层，直接看到它与周围空间的关系以及装修前后的视觉差异。

## 装修全息投影

- 投影使用数字孪生现有楼层坐标、房间尺寸和相邻连线，不让 AI 猜房间位置。
- 目标房间使用所选方案的配色、材质、照明、家具和氛围视觉令牌重新渲染。
- 同一楼层的其他房间保持当前真实装修，方便判断新方案是否与周围环境协调。
- 目标节点拥有明确的“装修投影”高亮和呼吸效果；减少动画模式会自动关闭动画。
- 侧边栏同时呈现当前状态与确认后的 BEFORE / AFTER 对照，以及方案影响标签。

## 安全边界与维护性

- 投影引擎是纯函数，不修改数字孪生、建筑状态或候选方案。
- 选择方案只更新经营中枢的临时界面状态，不写入 MVU。
- 目标空间不存在时返回空结果，不猜造坐标或房间 ID。
- 只有点击“应用装修”后，原有装修事务才会写入空间、事件与联动队列。
- 投影与装修确认共用同一个方案对象，避免预览一种效果、实际写入另一种效果。

## 工程与本地验收

- 自动化回归测试：82/82 通过。
- 新增两项投影引擎测试，覆盖目标视觉替换、其他空间保持、输入不变和未知空间拒绝。
- 完整经营流程验证投影出现时 MVU 仍是基础装修，确认后才真正改变。
- 浏览器验收覆盖桌面与窄屏，检查楼层布局、前后对照、目标高亮、横向溢出和运行错误。
- 测试期间没有调用真实 AI，也没有发送 SillyTavern 对话。
- 在线版和离线版仍各自只有一条酒馆助手脚本；角色卡和世界书使用独立 `0.3.0-16` 名称。
