# 多合一迁移功能对照

本文件是迁移验收合同，不是“已经改了多少文件”的流水账。构建检查会确保原卡全部纳入范围的启用脚本都按原始内容进入单文件构建；测试会确保下面 22 个模块都存在功能合同，避免未来重构时悄悄漏掉功能、CSS 或界面布局。

当前结论：原卡启用且本阶段纳入范围的 22 个模块已全部迁移，原貌保真模块 22 个，简化替代模块 0 个，漏迁移模块 0 个。

“原貌保真”表示统一运行时可以管理顺序、版本、依赖和状态，但不改写原模块的 HTML、CSS、图标、布局、动画或交互。未来只有在逐功能和真实 SillyTavern 视觉回归都对齐后，才允许用新实现替换单个原模块。

明确不在本轮范围：`03-switcher`（由统一模块运行时取代）、原卡未启用的悬浮球示例和 25～29 二改脚本，以及按产品决定暂缓的大富翁。它们不是漏迁移。

功能范围：

- MVU：固定版本框架加载、官方 Zod schema、跨字段校验。
- 公寓与入口：二维楼层/房间、建造装修、招募驱逐、关系、悬浮菜单、小手机。
- 微信玩法：数据库、AI 回复、正文/世界书同步、表情包、作者私聊。
- 动态世界：租客动态分析、队列、租客档案、天气、新闻、城市地图、世界地图、音乐。
- 显示与创作：正文美化、自定义招募/租客标签、创意工坊本地素材、预设、导入导出、云端、管理员、世界观及开场白应用。

机器可读的逐模块细目位于 `scripts/migration-feature-contract.mjs`，并由 `tests/migration-coverage.test.mjs` 验证。
