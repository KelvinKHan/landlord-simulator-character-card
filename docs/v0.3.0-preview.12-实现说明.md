# v0.3.0-preview.12 实现说明

这一版让建筑不再只是当前状态的平面图。数字孪生增加“空间记忆”图层：装修、入住、移动、关系火花和双人生活等已经确认的事情，会按照真实建筑与房间位置变成可查看的生活回声。

## 回声如何归档

- 只读取 MVU 中已经存在的事件列表，不创建第二套历史数据库。
- 事件必须同时匹配当前建筑 ID 和真实空间 ID，才进入对应房间。
- 没有空间 ID 的接管等建筑级事件进入建筑回声，不会随便归到某间房。
- 其他建筑的事件被严格隔离。
- 参与人物 ID 会解析成当前人物姓名，方便详情展示。

## 记忆强度不是惩罚

- 关系场景权重最高，其次是关系火花和建筑场景。
- 装修、人物加入、具身感受和移动同样会留下不同强度的痕迹。
- 权重只决定视觉高亮与主导颜色，不产生维护费用、倒计时或遗忘惩罚。
- 强度限制在 0—100 内，事件再多也不会破坏叠图样式。

## 数字孪生表现

- 第四图层继续使用原来的确定性房间坐标和相邻连线。
- 房间显示回声数、主导事件类型和记忆强度条。
- 没有回声的空间降低饱和度，让真正发生过生活的空间自然突出。
- 详情面板显示最近五段回声，包括类型、时间、标题、摘要与参与人物。
- 明亮、暗色和窄屏布局沿用经营中枢现有视觉系统。

## 本地验收

- 自动化回归测试：70/70 通过。
- 测试覆盖当前建筑隔离、真实空间归档、建筑级事件分离、参与人物解析、稳定签名和强度边界。
- 经营中枢集成测试验证第四图层切换、房间数据属性和空间记忆详情。
- 浏览器验收覆盖 1280px 宽屏和 760px 窄屏，四图层按钮、房间热力和详情面板无横向溢出。
- 全部测试使用本地固定数据，没有调用真实 AI，也没有发送 SillyTavern 对话。
- 在线版和离线版仍各自只有一条酒馆助手脚本；角色卡和世界书使用独立 `0.3.0-12` 名称。
