# v0.3.0-preview.2 实现说明

## 这一版的定位

这一版继续把 Landlord OS 从底层能力变成玩家真正能看见、能控制、能反悔的经营界面。它不增加生存压力，也不引入存档迁移；重点是让装修、招募、探索和跨频道联动更直观、更安全。

## 新增能力

- 可交互数字孪生：默认聚焦有内容的楼层，支持楼层切换、房间检查、人物占用、装修详情和相邻关系发光连线。
- 经营时光回溯：接管、装修、招募和探索会记录为当前会话操作，可撤销和重做。
- 冲突保护：回溯只恢复该次操作实际改变的路径；其他脚本产生的不相关变化会保留，同一路径被再次修改时则拒绝覆盖。
- 联动投递预览：正文、微信、新闻和建筑草稿可以单条或按频道批量预览，确认前不会调用任何端口。
- 真正的正文联动：确认后使用酒馆助手 `injectPrompts` 以 system / depth 0 注入，并设置 `once: true`，只影响下一次生成。
- 批量投递容错：成功项标记已读取，失败项继续留在队列中，不会因为一项失败丢失整批草稿。

## 安全边界

- 本轮自动验收仍会阻断 `generate` 和 `generateRaw`，没有调用真实 AI。
- 正文注入、微信写入和新闻写入都必须经过玩家显式确认。
- 经营回溯只存在于当前脚本会话，不是存档迁移，也不会改写旧存档格式。
- 原卡 22 个启用模块、世界书、正则、开场白和美化界面继续原貌进入多合一构建。

## 验证结果

- 完整迁移门禁通过：基线往返无损，22 个原貌模块无遗漏，3 个产品模块进入构建。
- 44 项自动测试全部通过，覆盖任务状态机、真实 AI 阻断、联动预览与确认、经营回溯冲突保护、逐步感知、稳定身份和数字孪生布局。
- 数字孪生、经营回溯和联动预览均已使用本机 Chrome 截图验收桌面布局。
- 在线版和离线版各自只有 1 条酒馆助手脚本，并使用 `0.3.0-2` 独立角色卡名和世界书名。

真实 SillyTavern 的自动点击验收仍受本地 Basic Auth 限制；本轮没有读取或修改认证配置。
