# v0.3.0-preview.10 实现说明

这一版把上一版的关系火花继续向“模拟人生式生活网络”推进。系统不只列出关系卡，还会把当前建筑中的人物、所在空间、潜在相遇和已确认关系编译为一张实时关系星图。

## 星图表达什么

- 每个人物是一个节点，颜色使用人物自己的视觉身份主色。
- 同一生活空间形成人物群落，并标明空间名和当前人数。
- 待确认的关系火花是一条流动虚线。
- 已经确认的双向关系是一条发光实线。
- 侧栏统计人物、生活空间、确认关系、潜在火花和跨世界连接。

## 为什么不是静态画布

- 图中不保存第二份人物坐标，避免关系图与 MVU 位置错位。
- 每次渲染都从当前人物位置和空间占用重新编译确定性坐标。
- 人物换房后会进入新的空间群落，旧的潜在线自然消失。
- 已确认关系属于人物本身；即使双方暂时分开活动，实线仍会保留。
- 同一状态得到同一布局和签名，方便测试、调试与后续叠加交互。

## 视觉与适配

- 星图使用原经营中枢的配色变量，可随明亮/暗色主题变化。
- SVG 节点、空间轨道、潜在线和确认线各有独立语义样式。
- 支持减少动画偏好，关闭流动虚线动画。
- 760px 窄屏下星图与信息面板自动改为上下布局，没有横向溢出。
- 修复主网格缺少最小高度约束导致长内容被外壳裁切的问题。

## 本地验收

- 自动化回归测试：64/64 通过。
- 测试覆盖节点边界、跨世界连接、潜在线转确认线、人物换房后群落重排，以及已确认关系跨空间保留。
- 浏览器检查了 1280px 宽屏和 760px 窄屏；长页面内部滚动、星图、信息侧栏和后续租客卡均可见。
- 全部测试使用本地固定数据，没有调用真实 AI，也没有发送 SillyTavern 对话。
- 在线版和离线版仍各自只有一条酒馆助手脚本；角色卡和世界书使用独立 `0.3.0-10` 名称。
