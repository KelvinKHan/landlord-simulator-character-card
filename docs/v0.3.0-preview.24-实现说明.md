# v0.3.0-preview.24 实现说明

## 这次完成了什么

本版是一次真实宿主闭环版。它保留 preview.23 的跨世界共创装修，同时把此前已经完成的统一任务中心、事件总线、逐步感知、租客具身化和数字孪生放进官方 SillyTavern 与酒馆助手中做无 AI 端到端验收。

## 修复的真实问题

原微信模块的 ChatDB 只有在玩家先打开一次微信 APP 后才会初始化。经营中枢只检查到函数存在，因而会显示“频道可用”，但第一次投递仍会失败。

现在桥接层会在玩家显式确认微信投递后：

1. 从 SillyTavern 当前上下文读取聊天 ID。
2. 自动初始化或切换 ChatDB。
3. 创建对应经营群聊并写入消息。
4. 成功后才把联动项标记为已读取；失败仍保留在队列中。

这意味着玩家不再需要记住“先打开微信一次”这种隐藏前置条件。

## 四频道闭环

- 正文：以一次性、系统层、深度 0 的上下文投递到下一次生成，不会自动触发 AI。
- 微信：写入原有 ChatDB，并在原小手机微信列表中出现。
- 新闻：写入原有新闻模块，并在“今日头条”中出现。
- 建筑：完成内部事件消费，所有频道处理完后队列清零。

四个频道读取同一条经营事件，不各自编造版本；每次投递都必须先预览并由玩家确认。
