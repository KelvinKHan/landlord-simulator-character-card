# v0.3.0-preview.19 实现说明

这一版让多建筑经营有了真正的横向视野。资产总览不再需要逐栋点进去猜“哪里更值得玩”，经营态势雷达会用同一套确定性指标比较所有已接管建筑，并指向当前最有成长空间的位置。

## 跨建筑经营态势雷达

- 每栋建筑生成舒适、功能、活力、吸引四轴雷达图和综合脉冲环。
- 卡片显示真实人物数、来源世界数、空置空间数和已激活协同数。
- 当前经营焦点拥有独立高亮；点击雷达卡仍复用原有进入建筑动作。
- 全局摘要汇总已接管建筑、版图人物、来源世界、可塑空间和活跃协同。
- 最高脉冲建筑会成为当前版图聚光点。

## 爽感导向的下一步建议

- 每栋建筑从真实空间脉冲中寻找最有成长余地的位置。
- 系统识别该空间当前最弱的维度，并建议安排人物、补足设施、装修记忆点或增加生活软装。
- 建议只告诉玩家“哪里可能更有趣”，不扣钱、不倒计时、不制造经营失败。
- 全局焦点从全部已接管建筑中选择，不让未接管医院或写字楼提前影响判断。

## 工程与本地验收

- 自动化回归测试：91/91 通过。
- 新增三项纯函数测试，覆盖单总部、接管第二栋后的跨建筑比较和未接管建筑隔离。
- 完整经营流程验证接管医院后雷达卡从一张自动增加到两张。
- 浏览器验收使用总部与医院的双建筑本地状态，覆盖桌面和 760px 窄屏雷达图、汇总与焦点建议。
- 测试期间没有调用真实 AI，也没有发送 SillyTavern 对话。
- 在线版和离线版仍各自只有一条酒馆助手脚本；角色卡和世界书使用独立 `0.3.0-19` 名称。
