# v0.3.0-preview.6 实现说明

这一版把已经完成的建筑运行脉冲和租客具身生活重新叠回数字孪生，让复杂经营信息拥有明确空间位置。玩家不需要在表格之间记忆“哪个分数属于哪间房”，直接切换图层就能看见。

## 三层数字孪生

### 空间结构层

- 保留原有确定性房间布局、面积比例、楼层切换和相邻连接。
- 继续显示装修材质、配色、家具标记、房间占用者和逐步感知结果。

### 运行体感层

- 每个房间直接显示建筑运行脉冲的综合分与高光、顺畅、蓄能等状态。
- 房间颜色和底部传感条随真实运行分变化。
- 详情面板显示舒适体感、功能兑现、生活活力、空间吸引和设施健康。

### 租客感受层

- 真实有人居住的房间按人物视觉身份和空间契合度高亮。
- 无人空间主动降噪，避免整张图都抢夺注意力。
- 详情面板直接显示当前人物对该房间的具身反应；多位人物同处时逐条呈现。

## 一致性与安全性

- 三层图共用同一个建筑 ID、楼层 ID、空间 ID 和确定性坐标，不新增重复地图状态。
- 图层切换只改变可视化，不写 MVU、不触发任务、不调用 AI。
- 装修、招募、人物移动或感受确认后，图层会从最新状态重新编译。
- 原来的空间详情、装修入口、相邻连接和楼层聚焦继续可用。

## 本地验收

- 自动化回归测试：55/55 通过。
- 经营中枢流程测试覆盖三层切换、运行传感详情和租客契合高亮。
- 本地 Chrome 已分别渲染运行体感层和租客感受层，房间图、传感条、人物高亮和详情面板显示正常。
- 在线版和离线版仍各自只有一条酒馆助手脚本；原有 22 个启用模块零遗漏。
- 全部测试没有发送真实 SillyTavern 对话，也没有调用真实 AI。
- 角色卡、世界书和构建产物使用独立的 `0.3.0-6` 名称，避免与旧版本冲突。
