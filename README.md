# 房东模拟器角色卡

这是用于维护和优化 SillyTavern 角色卡“房东模拟器”的公开仓库。

当前基线版本为 **Z5.20**。首个提交只保存从 SillyTavern 导出的原始文件和开发参考资料，不修改角色卡内容。

## 目录

- `角色卡/原始导出/`：从 SillyTavern 导出的原始 JSON 与 PNG，作为不可修改的回退基线。
- `角色卡/工作区/`：后续拆分、编辑和构建角色卡时使用。
- `docs/参考项目.md`：本项目可能使用的规范、插件与模板资料。

## 当前文件

- `房东模拟器Z5.20.json`：SillyTavern Character Card V3（`chara_card_v3`，规范版本 3.0）。
- `房东模拟器Z5.20.png`：SillyTavern 导出的 PNG 角色卡。

## 开发原则

1. 原始导出文件保持不变，所有调整在工作区中进行。
2. 每次发布保留明确的版本号和可回退文件。
3. 优先验证世界书、酒馆助手脚本、正则脚本、MVU 状态管理与 EJS 模板的兼容性。
4. 公开发布前检查凭据、本机路径和个人信息。
